# Horcrux

A blank diary that writes back.

The book belongs to Pragyaan Gaur, twenty years old, from Delhi, who put a memory of himself inside it in the way Tom Riddle did in the story. Whoever finds the page writes on the right hand side, the words soak into the paper, and the memory answers in ink. It is polite, it is calm, and it is far too interested in who you are. A small language model runs inside your own browser, so nothing anyone writes ever leaves their machine.

The diary is at https://pragyaangaur.github.io/Horcrux/
